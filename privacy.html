爱拍提词器 隐私政策

更新日期：2026 年 11 月 8 日

本政策说明开发者 jessel 的爱拍提词器在 iPhone 和 iPad 上如何处理你的信息。App 无需注册账户，开发者目前不运营脚本或录像云端存储服务，也未集成广告、跨 App 跟踪或第三方分析 SDK。

本机内容与设备权限

你创建或导入的脚本、文件夹、提词设置和在 App 内录制的视频保存在设备上。相机和麦克风用于预览、录像及语音跟随；你可以在 iOS 设置中撤销权限。语音跟随要求设备端语音识别可用，不支持时该功能无法启动。悬浮提词会在系统允许的画中画或实时活动界面显示你选择的文字与控制信息。

可选 AI 服务：数据、接收方与用途

AI 是可选功能。未经你允许，App 不会发起 AI 请求。检测模型或保存服务商连接时，会把 API Key 作为认证信息和模型列表查询发送给该服务商，以验证访问权限；不会发送文稿。生成或修改文稿时，会把当前脚本全文、你选择或输入的提示词、所选模型和 API Key 直接发送给该服务商，以生成结果预览；即使提示词未引用正文，也会附上全文。文稿或提示词中包含的个人信息也会一并发送。App 不会将录像、照片、联系人或麦克风音频附加到 AI 请求中。

这些 HTTPS 请求还会让服务商收到常规连接和请求信息，例如公网 IP 地址、请求时间及 API／客户端请求头。服务商可能通过 API Key 将请求关联到你的服务商账户，用于认证、计费、安全和防滥用。开发者不接收或中转 AI 请求，不出售这些内容，也不将其用于广告或模型训练。Key 存于设备 Keychain；模型、连接状态和授权记录存于本机。生成结果保持预览状态，直到你选择应用或复制。

授权与选择

连接服务商和生成内容前，App 内的确认页会说明接收方与固定接口、数据和用途，并提供该服务商的数据政策、服务条款及本政策链接。取消不会为该操作发出请求。授权适用于你随后主动发起、属于同一已告知服务的请求，不会自动开始生成。已告知的数据、接收方、用途或服务商政策信息发生实质变化时，会重新征求同意。你可以在 AI 服务商设置撤销连接授权，在 AI 魔法撤销内容发送授权；撤销后，后续请求须重新同意，但不会删除已发送的数据。撤销授权会保留 API Key 和模型选择。

服务商与保护措施

App 只使用下列固定 API 服务。我们要求接收方对共享的个人数据提供与本政策相同或同等的保护：仅用于已说明的服务及必要的安全或法律目的，保密并采取适当安全措施，限制访问，以及提供保留与删除控制。我们依据其公开 API 协议和数据政策核查这些保护。这不代表零留存承诺或另行签订的特殊协议。服务商账户设置、可选数据共享计划和法律或安全例外可能影响处理方式；发送敏感内容前请查看适用条款。

  • OpenAI API — api.openai.com/v1。API 内容默认不用于训练。标准防滥用日志可能包含内容，通常最多保留 30 天，存在例外；账户主动加入的计划及特定模型规则可能不同。参见API 数据控制说明和服务协议。
  • Anthropic Claude API — api.anthropic.com。商业 API 条款禁止用客户内容训练。标准 API 输入与输出在 30 天内删除，合同、法律和安全要求除外；标记为违规的内容可能保留更久。主动提交反馈另有规则。参见API 训练说明、留存说明和商业条款。
  • 阿里云百炼（Bailian / DashScope） — dashscope.aliyuncs.com/compatible-mode/v1，中国内地北京接口。中国站服务协议的签约方为通义云启（杭州）信息技术有限公司。其业务数据条款限定按服务指示和法律要求处理，禁止未经授权用于训练，并提供安全和删除保护。调用数据可能依法保存；中国站条款未承诺统一的 30 天上限。独立的 Token Plan／Coding Plan 计划具有不同条款。参见中国站隐私说明和服务协议。

服务商可能依其协议和基础设施安排在你所在国家或地区以外处理数据；服务可用范围和账户要求各有不同。App 不会替你加入可选训练或反馈计划。申请删除服务商持有的数据，请使用该服务商的账户控制或支持渠道；删除本机文稿或撤销 App 授权无法删除服务商副本。停止使用 AI 不影响本机编辑与提词。

局域网与购买

选择局域网主机、显示器或遥控器角色后，附近设备可能看到你的设备名称；建立连接后，App 会向已连接设备传送所选脚本、显示设置、播放进度或遥控指令。连接由系统的加密会话处理；请只连接你信任的设备。PRO 购买、续订和退款由 Apple 处理；App 通过 StoreKit 读取商品与已验证的购买权益，不获取你的完整银行卡资料。

分享、保留和删除

只有你主动使用系统分享或导出时，选中的录像或内容才会交给你指定的接收方。本机脚本和录像保留至你在 App 中删除或移除 App；系统备份和 Keychain 项目的保留由 iOS 设置与系统机制决定，卸载 App 不保证清除已保存的 API Key。如不再使用某服务商，请到其平台撤销 API Key。删除本机文稿不会删除已发送给服务商的请求；开发者无法代你删除服务商持有的数据，请依其政策申请删除。Apple 所持数据的删除亦依 Apple 政策办理。
