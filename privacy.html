爱拍提词器 隐私政策

更新日期：2026 年 10 月 18 日

本政策说明开发者 jessel 的爱拍提词器在 iPhone 和 iPad 上如何处理你的信息。App 无需注册账户，开发者目前不运营脚本或录像云端存储服务，也未集成广告、跨 App 跟踪或第三方分析 SDK。

本机内容与设备权限

你创建或导入的脚本、文件夹、提词设置和在 App 内录制的视频保存在设备上。相机和麦克风用于预览、录像及语音跟随；你可以在 iOS 设置中撤销权限。语音跟随要求设备端语音识别可用，不支持时该功能无法启动。悬浮提词会在系统允许的画中画或实时活动界面显示你选择的文字与控制信息。

AI 服务

首次检测模型或保存 AI 服务连接前，App 会显示服务商名称和接口域名，并说明 API Key 会作为认证信息发送，模型查询请求会发往该接口；不会发送脚本文稿。你可以取消；未同意时不会发出该请求。授权仅适用于该服务商、接口和 API Key 组合，修改任一项后须重新同意，并可在 AI 服务接入页撤销。API Key 保存在本机 Keychain；服务商地址、模型和检测状态保存在本机。首次运行 AI 生成前，App 会再次单独说明接收方和数据范围，并请你明确同意；同意后，每次由你主动发起的请求会直接发送当前脚本全文、提示词、所选模型及认证 API Key。即使提示词未引用正文，也会附上全文。服务商会收到请求及常规网络连接信息，并依其服务条款和隐私政策处理或保存；开发者不接收这些请求。千问 AI 平台的官方文档说明，输入和输出仅在请求期间于内存中处理，响应返回后不会持久保存，也不会用于模型训练；平台会记录 Token 用量、时间戳和请求 ID 用于计费与频率限制，并说明 API 连接使用 TLS 1.2 或更高版本。详见数据处理说明及数据安全说明。不同服务商和套餐规则可能不同，请查看实际使用的服务条款。自定义接口由你指定，发送前应确认域名运营方及其数据保护政策。删除本机文稿不会删除已发送给服务商的数据；你可依其政策申请删除。开发者不会用文稿进行广告追踪。

局域网与购买

选择局域网主机、显示器或遥控器角色后，附近设备可能看到你的设备名称；建立连接后，App 会向已连接设备传送所选脚本、显示设置、播放进度或遥控指令。连接由系统的加密会话处理；请只连接你信任的设备。PRO 购买、续订和退款由 Apple 处理；App 通过 StoreKit 读取商品与已验证的购买权益，不获取你的完整银行卡资料。

分享、保留和删除

只有你主动使用系统分享或导出时，选中的录像或内容才会交给你指定的接收方。本机脚本和录像保留至你在 App 中删除或移除 App；系统备份和 Keychain 项目的保留由 iOS 设置与系统机制决定，卸载 App 不保证清除已保存的 API Key。如不再使用某服务商，请到其平台撤销 API Key。删除本机文稿不会删除已发送给服务商的请求；开发者无法代你删除服务商持有的数据，请依其政策申请删除。Apple 所持数据的删除亦依 Apple 政策办理。
