爱拍提词器 隐私政策

更新日期：2026 年 10 月 29 日

本政策说明开发者 jessel 的爱拍提词器在 iPhone 和 iPad 上如何处理你的信息。App 无需注册账户，开发者目前不运营脚本或录像云端存储服务，也未集成广告、跨 App 跟踪或第三方分析 SDK。

本机内容与设备权限

你创建或导入的脚本、文件夹、提词设置和在 App 内录制的视频保存在设备上。相机和麦克风用于预览、录像及语音跟随；你可以在 iOS 设置中撤销权限。语音跟随要求设备端语音识别可用，不支持时该功能无法启动。悬浮提词会在系统允许的画中画或实时活动界面显示你选择的文字与控制信息。

AI 服务

配置 AI 服务并检测模型时，App 会把 API Key 作为认证信息发送给所选服务商，并发送模型查询请求；这一步不会发送脚本文稿。首次运行 AI 生成前，App 会显示服务商、固定接口域名和将发送的数据，并请你明确同意。你同意后，每次由你主动发起的生成请求都会把当前脚本全文、提示词、所选模型和 API Key 直接发送给该服务商；即使提示词没有引用正文，也会附上全文。请求还会带有服务运行所需的常规网络和请求元数据。你可以取消发送，也可在 AI 魔法页面撤销后续发送授权。API Key 保存在设备 Keychain；模型和连接状态保存在本机。开发者不接收这些 AI 请求，也不使用文稿进行广告或模型训练。

我们只接入公开 API 条款提供与本政策相当隐私保护的服务商：这些服务默认不使用 API 提示词和回答训练模型，并将请求内容的常规留存限制在安全与服务运营所需期限。App 目前只提供 OpenAI API、Anthropic Claude API 和阿里云百炼（Alibaba Cloud Model Studio / DashScope）的固定接口。根据服务商现行公开的 API 规则，这些服务默认不使用 API 提示词和回答训练其基础模型；各家通常会为安全、滥用监测或服务运行短期保留请求内容，默认期限和例外并不完全相同。OpenAI 与 Anthropic 的账户设置或用户主动提交反馈可能改变数据用途；法律、安全和服务政策执行也可能产生额外保留。阿里云百炼的默认提示词与回答留存期限不超过 30 天，法律或安全需要除外。请在使用前查看OpenAI API 数据控制说明、Anthropic API 训练说明、Anthropic API 留存说明、阿里云百炼数据使用说明和阿里云百炼留存政策。服务商可能更新其规则；服务商收到的数据不受本机撤销操作影响。删除本机文稿不会删除已发送的数据；如需申请删除或停止未来请求，请按服务商政策管理你的服务商账户或 API Key。

局域网与购买

选择局域网主机、显示器或遥控器角色后，附近设备可能看到你的设备名称；建立连接后，App 会向已连接设备传送所选脚本、显示设置、播放进度或遥控指令。连接由系统的加密会话处理；请只连接你信任的设备。PRO 购买、续订和退款由 Apple 处理；App 通过 StoreKit 读取商品与已验证的购买权益，不获取你的完整银行卡资料。

分享、保留和删除

只有你主动使用系统分享或导出时，选中的录像或内容才会交给你指定的接收方。本机脚本和录像保留至你在 App 中删除或移除 App；系统备份和 Keychain 项目的保留由 iOS 设置与系统机制决定，卸载 App 不保证清除已保存的 API Key。如不再使用某服务商，请到其平台撤销 API Key。删除本机文稿不会删除已发送给服务商的请求；开发者无法代你删除服务商持有的数据，请依其政策申请删除。Apple 所持数据的删除亦依 Apple 政策办理。
