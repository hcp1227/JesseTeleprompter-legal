愛拍提詞器 私隱政策

更新日期：2026 年 10 月 29 日

本政策說明開發者 jessel 的愛拍提詞器在 iPhone 和 iPad 上如何處理你的資料。App 無需註冊帳戶，開發者目前不運營腳本或錄影雲端存儲服務，也未集成廣告、跨 App 跟蹤或第三方分析 SDK。

本機內容與裝置權限

你創建或匯入的腳本、資料夾、提詞設定和在 App 內錄製的影片保存在裝置上。相機和麥克風用於預覽、錄影及語音跟隨；你可以在 iOS 設定中撤銷權限。語音跟隨要求裝置端語音識別可用，不支持時該功能無法啟動。懸浮提詞會在系統允許的畫中畫或實時活動界面顯示你選擇的文字與控制資料。

AI 服務

設定 AI 服務並檢測模型時，App 會將 API Key 作為驗證資料傳送給所選服務商，並傳送模型查詢請求；此步驟不會傳送腳本文稿。首次執行 AI 生成前，App 會顯示服務商、固定介面網域及將傳送的資料，並請你明確同意。你同意後，每次由你主動發起的生成請求都會將目前腳本全文、提示詞、所選模型和 API Key 直接傳送給該服務商；即使提示詞沒有引用正文，也會附上全文。請求亦會包含服務運作所需的一般網絡及請求中繼資料。你可以取消傳送，也可以在 AI 魔法頁面撤銷日後傳送的授權。API Key 保存在裝置 Keychain；模型和連線狀態保存在本機。開發者不會接收這些 AI 請求，也不會將文稿用於廣告或模型訓練。

我們只接入公開 API 條款提供與本政策相當私隱保障的服務商：這些服務預設不會使用 API 提示詞和回覆訓練模型，並將請求資料的一般保留限制在安全及服務運作所需期限。App 目前只提供 OpenAI API、Anthropic Claude API 和阿里雲百煉（Alibaba Cloud Model Studio / DashScope）的固定介面。根據服務商現行公開的 API 規則，這些服務預設不會使用 API 提示詞和回覆訓練其基礎模型；各家通常會為安全、濫用監測或服務運作而短期保留請求資料，預設期限及例外並不完全相同。OpenAI 與 Anthropic 的帳戶設定或使用者主動提交意見可能改變資料用途；法律、安全及服務政策執行亦可能導致額外保留。阿里雲百煉預設提示詞與回覆的保留期限不超過 30 天，法律或安全需要除外。使用前請查看OpenAI API 資料控制說明、Anthropic API 訓練說明、Anthropic API 保留說明、阿里雲百煉資料使用說明及阿里雲百煉保留政策。服務商可能更新其規則；裝置上的撤銷操作不會影響服務商已收到的資料。刪除本機文稿不會刪除已傳送的資料；如需申請刪除或停止未來請求，請依服務商政策管理你的服務商帳戶或 API Key。

局域網與購買

選擇局域網主機、顯示器或遙控器角色後，附近裝置可能看到你的裝置名稱；建立連接後，App 會向已連接裝置傳送所選腳本、顯示設定、播放進度或遙控指令。連接由系統的加密會話處理；請只連接你信任的裝置。PRO 購買、續訂和退款由 Apple 處理；App 通過 StoreKit 讀取商品與已驗證的購買權益，不獲取你的完整銀行卡資料。

分享、保留和刪除

只有你主動使用系統分享或匯出時，選中的錄影或內容才會交給你指定的接收方。本機腳本和錄影保留至你在 App 中刪除或移除 App；系統備份和 Keychain 項目的保留由 iOS 設定與系統機制決定，卸載 App 不保證清除已保存的 API Key。如不再使用某服務商，請到其平台撤銷 API Key。刪除本機文稿不會刪除已傳送給服務商的請求；開發者無法代你刪除服務商持有的資料，請依其政策申請刪除。Apple 持有的資料亦依 Apple 政策辦理。
